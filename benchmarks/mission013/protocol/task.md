# Morrow Print Room — original demonstration task

Create a fictional community print-studio workshop programme. It must clearly
identify itself as a local demonstration, with no real booking, payment, external
requests, testimonials, certification, customer claims or manufactured urgency.
Offer three original workshop choices with readable practical information and a
persistent selected value. A user can select a session, inspect useful details,
enter a name and prepare a local request draft. The result must honestly say that
nothing was sent and no place was reserved. A real pending local operation should
have stable loading feedback; recoverable validation must preserve choices/input.
Use the existing fictional paper/ink/vermilion tokens, local fonts, an editorial
headline, one relevant print artifact and meaningful section hierarchy. Native
controls, keyboard/focus feedback, press/selection and confirmation microinteractions,
reduced-motion parity, and 320/375/768/1440 responsive layouts are required.

Controller-authored demonstration only; not an independent agent trial or aesthetic
comparison. Record actual UDI command responses before implementation. Inspect only
needed direction/motion/critique IDs. Keep screenshots/browser profiles ignored;
retain compact essential assertions and guidance-to-decision evidence. All material
is original UDI/MIT, and no historical application is copied or modified.
