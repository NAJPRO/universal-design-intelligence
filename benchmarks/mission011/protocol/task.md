# Frozen task and criteria — Mission 011

Use the exact Northstar Supply synthetic records and tokens copied from the original Mission 010 C fixture. All source is original UDI/MIT. No external user project, assets, dependencies or services.

Primary narrow task: find a product, read name/SKU/status/stock/price and edit an authorized record. Read-only records retain identity/values and a permission explanation. Secondary task: compare columns for several records; horizontal comparison is legitimate. Keep every original field through table or labeled details. Preserve search, combined filters, Clear/Retry, invalid-entry retention, unsaved confirmation, save and cancel. Record-summary mode must not be forced for comparison.

Baseline: an unchanged COPY of Mission 010 C's interface (not the original directory). After: a controller-authored reference adaptation to revised contracts. Both use identical data, tokens, task and browser. This is a paired implementation/contract check, NOT independent agent generation, blind design scoring or a causal UDI-quality experiment. No additional coding agents are invoked.

Capture 375/768/1440 CSS px by 1000, plus 375 by 500 for editing; DPR 1. Capture populated, empty, error and edit, and the explicitly requested narrow comparison view. Test action access from horizontal origin, named comparison scrolling, keyboard/focus on resize, summary detail access, no unauthorized edit, filter/recovery behavior and short-dialog scrolling. Also simulate a shorter viewport (375 by 320); do not describe it as a real OS keyboard test.

Confirm failures only from direct scoped evidence: unintended page overflow with an ordinary offending node, essential action horizontal travel, inaccessible critical truncation, unrevealable dialog action, observed focus/draft loss. Treat nested regions, hidden scrollbar cues, hidden priority-column tradeoffs and BODY stops as review warnings. Record browser/assistive-tech limits; disappearance of a scrollbar is never a success metric.
