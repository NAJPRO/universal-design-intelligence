# Contributing

Thanks for helping improve UDI. The project is early-stage; please check [docs/roadmap.md](docs/roadmap.md) and open an issue before substantial work.

## Development setup

1. Install Node.js 22+ and pnpm 12+.
2. Run `pnpm install`.
3. Run `pnpm check` before submitting changes.

## Contribution guidelines

- Keep changes focused and preserve existing user-project behavior.
- Add tests for changed behavior, including edge cases.
- Keep the MVP offline-first and avoid unrequested dependencies.
- Cite the source and license for contributed knowledge. Do not copy third-party catalog content without checking its license and attribution requirements.
- Do not claim agent compatibility or visual/accessibility validation that has not been tested.

Submit changes as a pull request with a short explanation, validation commands, and any known limitations.
