# Changelog

All notable changes to UDI are documented here.

## [0.1.0] - 2026-10-27

- Add a local-first CLI for deterministic catalog search and design recommendations.
- Add global, project-scoped, and portable skill/runtime installation with preview, ownership tracking, and overwrite protections.
- Add `udi doctor` diagnostics and Codex, Claude Code, Cursor, and Antigravity static adapters.
- Bundle the canonical design skill and progressive-disclosure references in the CLI package.
- Document that only Codex live discovery and execution are confirmed; other adapters are not represented as live-tested.
- Record an independent, unofficial Lamborghini showcase built with the globally installed skill and a later remediation pass. This case study includes responsive, interaction, and automated accessibility checks, plus stated remaining limitations. It is not a controlled comparison or a performance claim, and the project is not affiliated with Automobili Lamborghini S.p.A.
