# Security policy

UDI is pre-release software. Please do not report security issues in public until maintainers have established a private reporting channel. Until then, contact the repository maintainers privately if contact details are available, and do not include credentials or unrelated personal data.

The CLI is designed to work locally and should not require API keys or send project files to a remote service. Report unexpected network access, unsafe writes, or dependency vulnerabilities as security concerns.
