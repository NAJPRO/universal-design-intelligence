## Decisions recommended for review

- Preserve the deterministic, offline runtime and existing safe installation architecture.
- Model industry, application type, user role, task, and brand evidence independently.
- Rank multiple eligible profiles and retrieve rules, patterns, and anti-patterns with coverage accounting.
- Start domain implementation with **e-commerce product administration**, while keeping storefronts separate.
- Make visual inspection evidence explicit and keep aesthetic judgment separate from automated checks.
- Ship the narrow retrieval foundation first; six complete domain packs and complex editors are later work.
